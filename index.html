3D Model Grabber

Find and download 3D model files referenced by a web page
GitHub settings (needed for "Run on GitHub")

Stored only in this browser (localStorage). Use a fine-grained token limited to this one repo with Actions: Read and write.

Options

A page opened from your disk can't read other websites directly (browser CORS rules), so the tool falls back to a public CORS proxy. If your network blocks those, use the Paste tab instead.

Most reliable method: console snippet (catches models loaded by JavaScript)

1. Open the target page and let the 3D viewer load. 2. Press F12 → Console. 3. Paste the snippet and press Enter (Edge may ask you to type allow pasting first). 4. The model URLs are copied to your clipboard – paste them in the box above.
